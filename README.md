# TaxMitra - India's Premier AI Tax Operating System

TaxMitra is a next-generation tax filing platform designed to simplify Indian Income Tax (ITR), GST, and Crypto compliances for individuals and professionals.

## 🚀 Key Features

*   **Zero-Touch Filing**: AI-powered ITR selection and auto-fill.
*   **Regime Optimization**: Algorithmically compares Old vs New regime to maximize savings.
*   **Crypto Tax Engine**: Automated Section 115BBH calculations and audit reports.
*   **Audit Defense**: Built-in document vault and AI-verified compliance checks.
*   **Professional Firm Hub**: Dedicated dashboard for CAs to manage client portfolios.
*   **AI Chatbot**: 24/7 Tax Assistant powered by Hugging Face LLMs.

## 🛠️ Technology Stack

*   **Frontend**: React, Vite, TypeScript, Tailwind CSS
*   **UI Components**: shadcn/ui, Framer Motion, Lucide React
*   **Backend/Database**: Supabase (PostgreSQL, Auth, Storage)
*   **AI Integration**: Hugging Face Inference API

## ⚡ Getting Started

1.  Clone the repository
2.  Install dependencies: `npm install`
3.  Set up environment variables in `.env`
4.  Run development server: `npm run dev`
